# Split list data (DESIGN.md §26.13, §66.30)

- `geoip-cn.txt`: China mainland IPv4 allocations from APNIC's public delegation statistics
  (`https://ftp.apnic.net/stats/apnic/delegated-apnic-latest`), merged into CIDRs by
  `scripts/make-geo-data.py` (2026-11-05); re-run it to refresh.

The site lists (`geosite:`) are not bundled: the App downloads the published `dlc.dat` of
[v2fly/domain-list-community](https://github.com/v2fly/domain-list-community) (MIT License,
Copyright (c) 2018-2019 V2Ray) on first launch and keeps it current (`Sources/App/GeoUpdater.swift`).
The test fixture `core/scripts/fixtures/geodata/geosite.txt` is the same format, generated by
`scripts/make-geo-data.py` from the project's 2026-11-05 sources.
