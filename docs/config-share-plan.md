## 一、现有配置在哪里

都在 App Groups 偏好域 `group.com.alwaysconnect.app` 的三个键里（`ProfileStore`），密码不在这里：

| 存放 | 内容 |
|---|---|
| `profile`（`Profile`） | `servers[]`（name / address / ciscoName）、选中的 `server`、`group`、`autoConnectOnLaunch`、`dismissedCisco`、旧 `allowNetworks` |
| `username` | Cisco 账号 |
| `appSettings`（`AppSettings`） | 通用开关、连接方式、`clientCertificate`、`directSites` / `directExceptions`、`proxyRoutes[]`、`egressProtection`、按需连接、热键、面板暂停开关 |
| 钥匙串 vault（`SecretVault`，§69.19，一个钥匙串条目） | Cisco 密码、代理密码 `proxy@proxy-<id>`、Hysteria2 混淆密码 `proxy-obfs@proxy-<id>` |

- 三类规则（分流直连、每个分流代理、每条出口保护）是同一种写法与解析器（`ListRule`，Rust 匹配器，§66.30），各带例外（§71.6）。
  规则里引用外部数据的只有 `geosite:名称[@属性]` 与 `geoip:cn`。
- 代理服务器自动按直连处理（§69.21），是派生值，不存、不导出。
- 出口保护已有"导入备份 / 导出备份"（`EgressPage`，JSON）：导入后都先暂停，打开时重新确认出口。新导入兼容这种旧 JSON。
- 本地 UUID、密码戳、健康版本、出口保护数字 id、暂停名单、掉线历史只在本机有意义，一律不导出。

## 二、导出

### 2.1 导出窗口

```
导出配置
──────────────────────────────────────────────────────────────
要导出的内容
  [✓] 分流直连        128 条规则 · 3 条例外
  [✓] 分流代理        2 个代理                         [选择…]
  [✓] 出口保护        3 条保护                         [选择…]
  [✓] Cisco 服务器    4 台 · 组
  [✓] 通用开关        断线保护、本地局域网直连 等 5 项

敏感信息
  [ ] 代理服务器地址（含 SNI、证书指纹、ECH）
  [ ] 代理的用户名和密码
        ⚠ 拿到文件的人能直接用你的代理，只发给信任的人
  Cisco 账号和密码不导出：每个人用自己的账号登录。

给对方的话（可选）  [________________________________]

[预览]                                       [取消]  [导出…]
```

- 五部分默认全选；"分流代理""出口保护"可以点"选择…"逐个勾。规则名单整份导出，不逐条勾（几百条逐条勾没意义，预览里能看全）。
  每份名单都连同它的例外一起导出：分流直连的例外、每个代理自己的例外、每条出口保护自己的例外。
- 敏感信息两项默认不勾。不勾时链接里对应的部分写成占位，如 `{host}`、`{password}`，对方导入时填自己的（2.3）。
- 勾了"用户名和密码"时，导出要读一次钥匙串 vault（同一个条目，最多一次授权框）；文件第一行写明"本文件含密码"。
- 没勾"服务器地址"时，若代理名、留言里出现了这台服务器的地址或用户名（例如把代理命名成 `198.51.100.9`），
  窗口里提示并给出"换成 代理 1"，避免隐去的值从名字里漏出去。
- "预览"显示的就是将要写入的完整文件文本；改任一选项立即重新生成。保存写入的字节与预览完全相同。

### 2.2 每类信息的处理

| 信息 | 处理 |
|---|---|
| 分流直连、分流代理、出口保护的规则与例外 | **原样导出**，包括私有网段、内部域名，不做删减（用户：可以原封导出） |
| 出口保护的国家、查不到出口时的处理、全局参数 | 原样 |
| 代理名、类型、端口 / 端口跳跃范围、混淆类型、上下行带宽、跳跃间隔、顺序 | 原样（都在一行链接里，名字和顺序除外） |
| Cisco 服务器列表（名称、Cisco 条目名、地址）、选中项、组 | 原样（用户：Cisco 节点是公司公用的） |
| 通用开关 | 原样 |
| 代理服务器地址、SNI、证书指纹、ECH | 勾选才导出，否则占位 |
| 代理用户名、密码、Hysteria2 认证、混淆密码 | 勾选才导出，否则占位 |
| Cisco 账号、Cisco 密码、登录证书 | 不导出（见第七节 1） |
| 按需连接、热键、连接方式开关、面板暂停状态 | 首版不导出（按需连接会自动断开 Cisco，按硬规则须由使用者自己开启） |

### 2.3 代理写成一行链接

每个代理在文件里就是 App「代理地址」框收的那种一行链接，不再拆成十几个字段：

```
socks5://{username}:{password}@{host}:1080
http://{host}:8080
hysteria2://{password}@{host}:443,20000-30000/?sni={sni}&obfs=salamander&obfs-password={obfs_password}&upmbps=50&downmbps=200&hop=30
```

- 写法：`socks5://`、`http://` 是常见的"类型://用户名:密码@地址:端口"；Hysteria2 用官方的 `hysteria2://认证@地址:端口/?参数`。
  `upmbps`、`downmbps`、`hop`、`ech` 这些参数 App 的编辑框现在就收、也这样显示；别的客户端不认识的参数一般会忽略。
  导出时链接里不写 `#名字`，名字放在单独的 `name` 里（导入时按名字判断同名）；没有名字的代理导出为"代理 1""代理 2"。
  导入时文件缺 `name` 而链接带 `#名字`，就用链接里的。
- 占位：链接里用花括号写的 `{host}`、`{username}`、`{password}`、`{obfs_password}`、`{sni}`、`{pin}`、`{ech}` 是分享者没导出的部分。
  花括号在链接里本来不允许直接出现（RFC 3986），真实值里有花括号时导出会写成 `%7B`，所以占位不会和真实值混淆。
  不认识的 `{…}` 让这个代理按无效跳过。
- 勾了敏感信息时，链接就是完整可用的标准链接，例如 `socks5://alice:p%40ss@198.51.100.9:1080`（值按链接规则做百分号编码）。
- 只在原代理有这一项时才写占位：没有账号的 SOCKS5 就是 `socks5://{host}:1080`；原来用指纹没用 SNI 的写 `pinSHA256={pin}`。
- 不用掩码（`198.51.*.*`、`ab***`）：掩码照样漏出一部分，对方又用不上。

### 2.4 三类名单：规则与例外

三类名单在文件里一律是一对 `rules` + `exceptions`，写法和 App 里的规则框完全相同；例外为空也写 `exceptions = []`，
让读的人知道这里可以放例外。例外的含义沿用 §71.6，三处不同，各节用一行注释写明：

| 名单 | `rules` | `exceptions`（例外） |
|---|---|---|
| 分流直连 `[split.direct]` | 命中的网站不走 Cisco | 命中的跳过分流直连，按默认路线走（连着 Cisco 时走 Cisco）；整份名单共用一组 |
| 分流代理 `[[proxy]]` | 命中的网站经这个代理 | 命中的跳过这个代理，继续匹配后面的代理和规则 |
| 出口保护 `[[egress.rule]]` | 要保护的网站 | 命中的不受这条保护，其余保护照常 |

带名字的分流直连分组（`[[split.direct.group]]`，旧版"现成分组"迁来的）只有 `rules`，例外仍用整份名单那一组。

## 三、格式：TOML

| 候选 | 注释 | 不选的原因 |
|---|---|---|
| **TOML 1.0** | `#` | — |
| YAML | `#` | 隐式类型（`no` 变成假、`0123` 变成数字），锚点能放大内容，规则行里的 `:` 手改易错 |
| JSONC / JSON5 | `//` | 没有统一规范，各家解析器不一致 |
| JSON（现有出口保护备份） | 无 | 不能写说明 |

TOML 有规范、字符串必须加引号、没有引用和包含其他文件的语法，`[[proxy]]` 正好对应一个个代理。
扩展名 `.toml`，默认文件名 `AlwaysConnect-分享配置.toml`。

```
[file]            kind = "alwaysconnect-share"、format = 1、app_version、exported（只到日期）、note、contains_secrets
[general]         通用开关
[cisco]           group、selected，[[cisco.server]] name + cisco_entry / address
[split.direct]    rules、exceptions，[[split.direct.group]] name + rules
[[proxy]]         name、link（一行链接，2.3）、rules、exceptions（数组顺序即匹配顺序）
[egress]          steer、prefetch、half_life_minutes，[[egress.rule]] name、rules、exceptions、countries、when_unverified
```

- 键名 snake_case，与 Swift 字段名解耦（出口保护内部叫 `sites`，文件里和另外两处一样叫 `rules`）；枚举写可读的词（`when_wrong`）。
- **注释少而清楚**（用户："注释不必多，清晰就行"）：文件头三行（这是什么、怎么导入、链接里 `{…}` 是什么），每节一行，
  只在值的含义看不出来时加行尾注释。注释由 App 固定生成，不含任何配置值；分享者的话只放 `note`。导入时忽略注释。
- **版本**：`format` 是整数，同一 `format` 只加可选字段。比 App 新的 `format` 整份拒绝并提示更新；
  不认识的键或代理类型跳过那一项并在预览里列出，不整份失败。`app_version` 只作参考。

## 四、导入

### 4.1 流程

1. **选文件**：设置 → 通用 → "导入配置…"。也接受现有出口保护 JSON 备份（只导入出口保护）。
2. **解析**（Rust，不改任何状态）：不是本格式、`format` 太新、语法错、超限（4.5）→ 一句话说明，结束。
   否则得到导入计划：每部分的新增、重复（跳过）、同名冲突、无效（带原因）、需要填写的占位。
3. **预览**：每部分选 **合并**（默认）/ **替换** / **不导入**；列出每条新增与跳过的规则、每个代理与保护；
   冲突项给选择（4.2）；链接里每个占位就地给一个输入框（地址、用户名、密码、SNI、证书指纹、ECH、混淆密码；密码用安全输入框），
   旁边也可以直接粘贴自己的整条链接替换。可以不填，没填齐的代理以"待补全"导入。
   文件带了密码时显示"文件里带了 N 个密码，将存进钥匙串"，密码本身只显示为圆点。
   底部写清后果，例如"会新增 23 条分流直连规则；2 个代理和 1 条出口保护导入后先停用"。
4. **写入**（4.4），显示结果和"撤销这次导入"。

### 4.2 合并、替换、同名与重复

| 部分 | 认作同一条的依据 | 合并 | 替换 |
|---|---|---|---|
| 分流直连规则 / 例外 | 规范化后的规则文本（Clash 行先转 v2fly） | 本机没有的追加，已有的跳过计数 | 整份换成文件里的 |
| 带名字的分组 | 名字 | 同名时补进缺的规则 | 同上 |
| 代理 | 名字（不分大小写） | 例外跟着代理走；同名三选一：**两个都留，导入的改名"名称（导入）"**（默认）/ 只更新规则和例外、保留本机服务器与密码 / 跳过；导入的排在本机代理之后 | 本机代理全部移除（确认框列名字），按文件顺序 |
| 出口保护 | 名字 | 同名：两个都留（默认）/ 替换这条 / 跳过；在本机重新编号 | 整体换成文件里的 |
| 出口保护全局参数、通用开关 | — | 逐项对比，默认保持本机，勾了才改 | 用文件里的 |
| Cisco 服务器 | `cisco_entry`，或地址 | 本机没有的追加；`cisco_entry` 在本机 Cisco 配置里找不到时用文件里的地址，地址也没有就请填或跳过；选中的服务器默认不切换（本机还没有选中的服务器时用文件里的） | 列表换成文件里的 |

文件内部的重复在解析时去重并在预览里列出。

### 4.3 导入后什么时候生效

- **分流直连规则与例外**确认后立即写入（预览已逐条列出，确认按钮写明条数）。按现有规则：名字类规则只在按网站分流时起作用；
  网段规则连着 Cisco 时也会加入断线保护的放行名单（§26.13），预览里单独标出"这几条网段在 Cisco 下也直连"。
- **生效前提照现有规则，导入不替对方改**：分流代理与出口保护在"连着 Cisco 连接方式"时不起作用（按网站分流或 Cisco 断开时才起作用），
  出口保护还要求断线保护开着。预览按对方本机当前状态逐条说明哪些导入的内容暂时不会起作用、去哪一页打开。
- **代理**默认停用。信息齐全的代理在预览里有"导入后打开"勾选（默认不勾）；勾了也先走现有的代理检测，通过才打开。
  没填齐的标"待补全"，补全前打不开。
- **占位的去处**：必填的占位（`{host}`、Hysteria2 的 `{password}` 与 `{obfs_password}`）没填，代理以"待补全"停用导入，规则照常导入；
  之后在分流代理页编辑这个代理，填好或粘贴整条链接、检测通过即可打开。可选占位（SOCKS5/HTTP 的 `{username}:{password}`、
  `{sni}`、`{pin}`）留空就去掉这一段，但仍按现有校验判断能否使用（例如 Hysteria2 用 IP 却既无 SNI 也无指纹，仍是"待补全"）。
  占位只认 `link` 里的；写在规则、名字、国家等别处，那一项按无效跳过并在预览里列出。
- **出口保护**默认暂停，同样有"导入后打开"（默认不勾），打开时走现有的出口确认。
- **通用开关**默认保持本机；把断线保护、审批提示卡从开改成关时写明影响（关断线保护会同时停掉出口保护，与连接页现有行为一致）。
- **不改**：连接方式（按网站分流）、选中的服务器、Cisco 账号与证书、按需连接、面板暂停状态。

### 4.4 写入与失败

- Rust 由"本机当前配置 + 文件 + 用户选择"算出完整的新 `AppSettings` 与 `Profile`，Swift 只负责写。
- 顺序：① 导入前的两个键存为撤销快照（同一偏好域的新键 `importUndo`）；② 新密码（文件带的或用户填的）一次写进 vault，
  失败则整次放弃；③ 写两个键，第二个失败就用快照恢复第一个，并删掉 ② 的新密码；④ 成功后按各页保存时的现有路径通知后台服务一次（分流名单与代理的域名推送、放行网段更新、出口保护更新），不加 XPC 方法。
  出口保护要用带 `updatingEgress` 的保存（普通保存会保留旧的出口保护），新代理写新的密码戳，让 App 重新读一次钥匙串。
  "替换"掉的旧代理密码留到撤销快照被下一次导入覆盖时才删，撤销能连密码一起找回。
- 写之前核对配置没被别处改过（比较快照），变了就重新出预览。
- 撤销：恢复两个键，删掉这次新写的密码；只保留最近一次。
- 卸载：`importUndo` 在 uninstall.sh 已整体删除的偏好域里；实现时在 `scripts/uninstall-test.sh` 加断言。

### 4.5 安全解析

- 只读用户在文件面板选中的那一个文件；≤ 1 MiB、UTF-8；不下载、不跟随任何链接，TOML 没有包含语法。
- 上限：代理、出口保护、Cisco 服务器各 ≤ 64，每个名单 ≤ 10000 条，单个字符串 ≤ 4096 字节；超限整份拒绝。
- 每个值过现有校验：规则用 `ac_list_rule_valid`（`regexp:` 用 regex-lite，线性时间）；代理用现有构造与 Hysteria2 安全底线
  （拒绝 `insecure`、IPv6 字面量、未支持参数）；国家代码（ISO 两位）、端口范围、出口保护 `permitsActivation` 与全局参数范围（`prefetch` 0–20、`half_life_minutes` 1–30）。
- `geosite:` 本机清单里没有：清单已下载 → 标无效跳过；还没下载 → 按原文保留（与现有行为一致），预览提示。

## 五、实现分工（遵守"常驻逻辑用 Rust"）

- `core/src/config_share.rs`（新）：导出生成（含注释与占位）、名字里漏出隐去值的检查、解析、合并计划、旧出口保护 JSON 识别；
  经 C ABI 暴露 `ac_share_export` / `ac_share_plan` 两个 JSON 进出的函数。加 `toml` crate 只用于解析，导出文本按固定顺序自己写；
  加依赖后重跑 `scripts/make-rust-notices.sh`。cargo test 锁住"生成的文本再解析回来与模型逐字段相同"。
- 链接解析共用一份：Hysteria2 已在 Rust（`ac_hysteria_parse_uri`）；`socks5://`、`http://` 与逗号写法现在在 Swift 的 `ProxyLink.parse`，
  随本功能移到 Rust，编辑框与导入用同一个解析器（实现时登记 DESIGN §32.5 迁移清单）。
- Swift：通用页两个按钮、导出与导入两张表单、文件面板、安全输入框、钥匙串读写、偏好写入与撤销。
- 开销：只在表单打开时运行，关上即释放；不加计时器、不常驻数据，常驻路径不变；实现汇报附 `footprint` 对照。
- 不新增系统文件；导出文件在用户选的位置，归用户所有。

## 六、首版范围

- 做：五部分的勾选导出（代理、出口保护可逐个勾）、两项敏感信息开关、TOML 导出（预览与文件一致）、
  导入预览、合并/替换、冲突选择、占位补填、待补全、导入后打开、撤销、兼容出口保护 JSON 备份。
- 以后再看：按需连接、双击文件打开（注册文件类型）、二维码/链接分享、文件签名或加密。

## 七、我替用户定的默认（不同意再改）

1. **Cisco 账号和密码不提供导出选项**。每个人用自己的账号登录，别人的密码对接收者没用，带出去反而是公司账号外泄；
   接收者第一次连接时照常输入自己的账号。
2. 两项敏感信息默认不勾；勾了"用户名和密码"时文件头写明含密码。
3. 代理写成一行标准链接，隐去的部分在链接里写 `{host}` 这类占位，不用掩码。
4. 同名代理和出口保护默认"两个都留"，导入的改名。
5. 按需连接首版不导出。
