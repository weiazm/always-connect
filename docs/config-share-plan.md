## 一、现有配置在哪里、哪些敏感

都在 App Groups 偏好域 `group.com.alwaysconnect.app` 的三个键里（`ProfileStore`），密码不在这里：

| 存放 | 内容 | 敏感程度 |
|---|---|---|
| `profile`（`Profile`） | `servers[]`（name / address / ciscoName）、`server`（选中的）、`group`、`autoConnectOnLaunch`、`dismissedCisco`、旧 `allowNetworks` | 服务器地址、Cisco 条目名、组名是**单位内部信息** |
| `username` | Cisco 账号 | **个人**，不导出 |
| `appSettings`（`AppSettings`） | 断线保护、自动局域网、审批提示卡、网站清单自动更新、连接方式（按网站分流）、`clientCertificate`（证书 SHA-256）、`directSites` / `directExceptions`、`proxyRoutes[]`、`egressProtection`、按需连接规则、热键、面板暂停开关 | 规则可能含内网名字与网段；代理地址、SNI、指纹能认出服务器；按需连接含 Wi-Fi 名称与内部 DNS |
| 钥匙串 vault（`SecretVault`，§69.19） | Cisco 密码（`账号@服务器`）、代理密码 `proxy@proxy-<id>`、Hysteria2 混淆密码 `proxy-obfs@proxy-<id>` | **机密**，不导出 |

其他相关事实：

- 三处规则（分流直连、每个代理、每条出口保护）同一种写法与解析器（`ListRule`，Rust 匹配器，§66.30），各带例外（§71.6）。
  规则里引用外部数据的只有 `geosite:名称[@属性]` 与 `geoip:cn`：清单由本机下载（§66.30），
  首次下载前 `geosite:` 按原文保留，有清单后不认识的名字会被拒绝。
- 代理服务器地址自动按直连处理（`proxyServerDirectRules`，§69.21），这是派生值，不存、不导出。
- 出口保护已经有"导入备份 / 导出备份"（`EgressPage`，JSON 原样导出）：导入后整体与每条都先暂停，打开时重新确认出口。
  本方案沿用这个原则，并让新导入兼容这种旧 JSON。
- 本地 UUID（代理 id、`healthRevision`）、`passwordStamp` / `obfsPasswordStamp`、出口保护数字 id、
  `egressPausedRules`、掉线历史都只在本机有意义。

## 二、分享范围（首版）

| 部分 | 导出默认 | 说明 |
|---|---|---|
| 通用开关 | 带上 | 断线保护、本地局域网直连、打开即连接、审批提示卡、网站清单自动更新 |
| 分流直连（含例外、带名字的分组） | 带上 | 用户点名要的"站点白名单" |
| 分流代理（SOCKS5 / HTTP / Hysteria2，含规则、例外、顺序） | 带上，服务器信息隐去 | 见第四节 |
| 出口保护（全局参数 + 每条规则） | 带上 | 规则与国家原样，导入后暂停 |
| Cisco 连接（服务器列表、选中项、组） | **默认不带**，导出时勾选 | 条目名、地址、组名都是单位内部信息，只适合发给同事 |
| 按需连接 | **首版不做** | 含 Wi-Fi 名称和内部 DNS 域；它会自动断开 Cisco，按硬规则必须由使用者自己开启，不宜随文件导入 |
| 热键、面板暂停状态、连接方式开关、登录证书、账号 | 不导出 | 个人习惯或本机状态；"按网站分流"需本机证书，由接收者自己开 |

导出界面按部分勾选，每部分标出条数。

## 三、格式：TOML

| 候选 | 注释 | 问题 |
|---|---|---|
| **TOML 1.0** | `#` 行注释、行尾注释 | 需加 `toml` crate（Rust 侧）；嵌套深时写法啰嗦，本配置最多两层，够用 |
| YAML | `#` | 隐式类型（`no`、`0123`、`1e3` 被转成别的类型），锚点/别名能做"十亿笑声"放大；规则行里的 `:` 要加引号，手改容易错 |
| JSONC / JSON5 | `//` | 没有统一规范，解析器各家不一样；面向普通人读写不友好；导出的注释也难放 |
| JSON（现在的出口保护备份） | 无 | 不能写说明 |
| 自定义行格式 | 随意 | 要自己写、自己维护规范，转发给别人时没有现成工具能检查 |

推荐 TOML：有规范、类型明确（字符串必须加引号，不会把 `NO` 当布尔），没有引用和包含其他文件的语法，
`[[proxy]]` 这种表数组正好对应"一个个代理/一条条保护"，接收者用任何文本编辑器都能读懂。
扩展名 `.toml`，默认文件名 `AlwaysConnect-分享配置.toml`。

**结构**（完整见示例）：

```
[file]            kind = "alwaysconnect-share"、format = 1、app_version、exported（只到日期）、note（分享者留言）
[general]         通用开关
[cisco]           group、selected，[[cisco.server]] name + cisco_entry 或 address
[split.direct]    rules、exceptions，[[split.direct.group]] name + rules
[[proxy]]         name、type、host、port / ports、username、password / auth、sni、pin_sha256、ech、obfs、obfs_password、
                  up_mbps、down_mbps、hop_seconds、enabled、rules、exceptions（数组顺序就是匹配顺序）
[egress]          steer、prefetch、half_life_minutes，[[egress.rule]] name、sites、exceptions、countries、when_unverified
```

- 键名用 snake_case，和 Swift 字段名解耦（文件是公开契约，内部字段改名不影响它）。枚举值写成可读的词
  （`when_wrong`，不写内部的 `whenWrong`）。
- **类型化占位**：凡是被隐去的值写成内联表 `{ fill = "<类型>", hint = "…", optional = true|false }`。
  类型：`host`、`username`、`secret`、`sni`、`pin_sha256`、`ech`、`gateway`、`group`。
  用表而不用 `"<请填写>"` 这样的字符串，是为了和真实值区分得一清二楚：解析器只认表，不会把某个碰巧长成 `<…>` 的名字当占位。
- **注释**：文件头写给接收者的说明（是什么、怎么导入、占位是什么意思、导入后什么先停用），每节开头说明这一节的作用和规则写法，
  关键字段行尾说明。注释全部由 App 生成，内容固定（只随 App 版本变），不夹带任何配置值；
  分享者自己想说的话只放在 `[file].note`（会被检查，见 4.3）。导入时注释一律忽略。
- **版本**：`format` 是整数。同一 `format` 内只加可选字段，不改含义；改含义才加一。
  App 读到比自己新的 `format` 整份拒绝，提示"请先更新 App"；读到不认识的键或代理类型，跳过那一项并在预览里列出，不整份失败。
  `app_version` 只作参考，不参与判断。

## 四、导出：每个字段怎么处理

四种处理："原样"、"默认隐去"（导出界面可改成保留）、"总是占位"（不能保留）、"省略"（不出现，也不留占位）。

### 4.1 字段表

| 字段 | 处理 | 理由 |
|---|---|---|
| Cisco 账号、Cisco 密码、登录证书（SHA-256） | 省略 | 个人凭据；证书只在本机钥匙串 |
| 代理密码、Hysteria2 `auth`、混淆密码 | 总是占位（`secret`） | 机密；导出**不读钥匙串**，所以文件里不可能出现密码，也不会因为导出多弹一次授权 |
| 代理用户名 | 总是占位（`username`，有用户名时才写） | 个人账号 |
| 代理地址 `host` | 默认隐去（`host`） | 能认出服务器；勾"包含代理服务器信息"才保留（例如分享者就是给朋友共用一台服务器） |
| Hysteria2 `sni`、`pin_sha256`、`ech` | 跟随上面的勾选，默认隐去 | 都能认出这台服务器；换成接收者的服务器后旧指纹必然不对 |
| 端口 / 端口跳跃范围、代理类型、混淆类型、上下行带宽、跳跃间隔 | 原样 | 不认出服务器，接收者照着填自己的服务器时有用 |
| 代理名、分组名、出口保护名 | 原样，经 4.3 检查 | 自由文本，可能夹带地址或账号 |
| 规则与例外（三处） | 原样，经 4.2 检查 | 用户要分享的正是这些 |
| 出口保护的国家、查不到出口时的处理、全局参数 | 原样 | |
| 代理与出口保护的开关状态 | 原样（只作参考） | 导入一律先停用，见第五节 |
| 通用开关 | 原样 | |
| Cisco 条目名、服务器名、组名 | 整节默认不导出；勾选后原样 | 单位内部信息 |
| 非 Cisco 条目的网关地址 | Cisco 节勾选后仍默认隐去（`gateway`），可改为保留 | 单位网关地址 |
| 本地 UUID、密码戳、健康版本、出口保护 id、暂停名单、掉线历史、`dismissedCisco`、旧 `allowNetworks` | 省略 | 只在本机有意义 |

**为什么用占位、不用掩码**：`198.51.*.*`、`ab***@` 这种掩码仍然漏出网段、运营商、账号前缀，对接收者又没用
（他总要换成自己的值）。所以文件里只放类型化占位加一句提示；预览界面也不显示掩码后的原值。

### 4.2 规则里可能指向内网的条目

逐条交给 Rust 判断，命中任一条件即标记为"可能是内部"：

- 网段落在私有/保留地址（`10/8`、`172.16/12`、`192.168/16`、`100.64/10`、`169.254/16`），或是单个地址（`/32`，常是自己的服务器）；
- 名字以 `.local`、`.lan`、`.internal`、`.corp`、`.home`、`.intranet` 结尾，或只有一段（无点）；
- 名字与本机的已知内部值有关：Cisco 网关地址及其上级域名、Cisco 条目里的地址、代理服务器地址（这些都在设置里，不需要读钥匙串）；
- `keyword:` / `regexp:` 命中上面任何一个名字。

标记的条目**默认不导出**，文件里只留一行固定注释"导出时去掉了 N 条可能指向内部网络的规则（内容不写进文件）"；
预览里逐条列出，可以改成"保留"。检测是启发式的，所以预览把"原样导出的规则"也全部列出，由分享者过目。

### 4.3 自由文本（名字、留言、提示）

检查所有会进文件的自由文本：

- 高置信，自动处理：含 `://` 的链接（尤其带 `用户:密码@`）、`password=`/`auth=`/`token=`/`obfs-password=` 一类键值、
  本机的已知值（代理地址、代理用户名、Cisco 账号、网关地址、组名）。名字里出现时整段替换成"代理 1""保护 2"这类编号名并标记；
  留言里出现时不能导出，要求分享者改掉。
- 低置信，只提醒：邮箱、IP 地址、20 位以上的十六进制/Base64 长串。

已知局限（写在导出界面帮助里）：导出不读钥匙串，所以识别不出"把密码原样敲进了代理名"这种情况，只能靠预览过目。

### 4.4 预览与文件一致

导出由 Rust 一次生成**完整文件文本**；预览窗口显示的就是这段文本（只读、可滚动、带语法着色可选），
旁边列出这次隐去/去掉了什么。点"保存"写入的就是同一段字节；任何选项变化都重新生成整段文本。
cargo test 锁住：生成的文本再解析回来，与导出前的模型（去掉被隐去的部分后）逐字段相同。

## 五、导入

### 5.1 流程

1. **选文件**：设置 → 通用 → "导入配置…"。也接受现有出口保护备份 JSON（按旧格式识别，只导入出口保护）。
2. **解析**（Rust，全程不改任何状态）：
   - 不是本格式、`format` 比 App 新、语法错、超过限制（5.5）→ 一句话说明，结束。
   - 否则得到"导入计划"：每部分的新增、重复（跳过）、同名冲突、无效（带原因）、需要填写的占位。
3. **预览**（一张表单，按部分分组）：
   - 每部分选 **合并**（默认）/ **替换** / **不导入**。Cisco 节默认"合并"但不切换选中的服务器；通用开关按 5.3 逐项。
   - 列出每一条新增与跳过的规则、每个代理与保护，冲突项给出选择（5.2）。
   - 需要填写的占位就地给输入框；机密用安全输入框。**可以不填**：没填齐的代理以"待补全"导入。
   - 底部写清后果，例如"会新增 23 条分流直连规则（这些网站在按网站分流时不走 Cisco）；2 个代理和 1 条出口保护导入后先停用"。
4. **写入**（5.4），然后显示结果和"撤销这次导入"。

### 5.2 合并、替换、同名与重复

| 部分 | 认作"同一条"的依据 | 合并 | 替换 |
|---|---|---|---|
| 分流直连规则 / 例外 | 规则规范化后的文本（`ListRule` 归一，Clash 行先转成 v2fly） | 本机没有的追加到末尾，已有的跳过并计数 | 整个名单与例外换成文件里的 |
| 带名字的分组 | 名字 | 同名时把缺的规则补进该分组 | 同上 |
| 代理 | 名字（不分大小写） | 同名时三选一：**两个都留，导入的改名"名称（导入）"**（默认）/ 只更新规则和例外，保留本机的服务器与密码 / 跳过 | 本机代理全部移除（确认框列出名字），其钥匙串密码保留到撤销快照失效（5.4） |
| 代理顺序 | 文件内顺序 | 导入的追加在本机代理之后 | 按文件顺序 |
| 出口保护规则 | 名字 | 同名时：两个都留（默认）/ 用导入的替换这条 / 跳过；新条目在本机重新编号 | 整体换成文件里的 |
| 出口保护全局参数 | — | 逐项对比，默认保持本机 | 用文件里的 |
| Cisco 服务器 | `cisco_entry`，或地址 | 本机没有的追加；`cisco_entry` 在本机 Cisco 配置里找不到时请填地址或跳过 | 列表换成文件里的（本机 Cisco 自动同步规则不变） |

文件内部的重复（同一条规则写两遍、两个同名代理）在解析阶段去重并在预览里列出。

### 5.3 不会"导入即生效"的东西

- 导入的**代理一律停用**；没填齐（缺地址、缺密码、Hysteria2 用 IP 却没有 SNI 和指纹）的标"待补全"，补全前打不开。
  打开时走现有的"保存前检测代理"。
- 导入的**出口保护每条都暂停**（沿用现有备份导入的做法），打开时重新确认出口。
- **通用开关**逐项显示"文件：开 / 本机：关"，默认保持本机；勾了才改。把保护类开关从开改成关（断线保护、审批提示卡）时额外写明影响。
- **不改**：连接方式（按网站分流开关）、选中的服务器、账号、证书、按需连接、面板上的暂停状态。
- 分流直连规则在确认后立即生效（预览已逐条列出，确认按钮写明条数与后果），这是唯一确认即生效的路由变化。

### 5.4 写入与失败

- Rust 由"本机当前配置 + 文件 + 用户的选择"算出**完整的新 `AppSettings` 与 `Profile`**，Swift 不做合并逻辑，只负责写。
- 写入顺序：
  1. 把导入前的 `appSettings`、`profile` 存为撤销快照（同一偏好域的新键 `importUndo`）；
  2. 接收者填的密码一次写进钥匙串 vault（新代理的新 id），失败则整次放弃，什么都没改；
  3. 写 `appSettings`、`profile`；第二个写失败就用快照恢复第一个，并删掉第 2 步刚写的密码；
  4. 成功后通知后台服务一次（走现有的设置变更路径，不加 XPC 方法）。"替换"掉的旧代理密码先留着，
     等撤销快照被下一次导入覆盖时才删除，这样撤销能把旧代理连同密码一起找回。
- 计划基于读到的配置算出，写之前核对配置没被别处改过（比较快照），变了就重新出预览。
- 撤销：恢复快照中的两键，删掉这次导入新写的密码；只保留最近一次，下一次导入时清掉上一次快照引用的旧密码。
- 卸载：`importUndo` 在已整体删除的偏好域里；实现时在 `scripts/uninstall-test.sh` 加断言。

### 5.5 安全解析

- 只读用户在文件面板里选中的那一个文件；文件 ≤ 1 MiB、必须是 UTF-8；不跟随链接、不下载任何东西、TOML 本身没有包含语法。
- 数量上限：代理 ≤ 64、出口保护 ≤ 64、Cisco 服务器 ≤ 64、每个名单 ≤ 10000 条、单个字符串 ≤ 4096 字节。超限整份拒绝。
- 每个值都过现有校验：规则用 `ac_list_rule_valid`（`regexp:` 用 regex-lite，线性时间）、代理用现有的链接/逗号写法构造与 Hysteria2 安全底线
  （拒绝 `insecure`、IPv6 字面量、未支持参数）、国家代码、端口范围、出口保护的 `permitsActivation`。
- 文件里出现机密的明文值（例如有人手写了 `password = "…"`）：不导入这个值，提示"密码请在本机填写"。
  这样分享格式永远不承载密码，接收者也不会被一份带密码的文件"顺手"写进钥匙串。
- `geosite:` 名字本机清单里没有：清单已下载 → 这条标无效跳过；清单还没下载 → 按原文保留（与现有行为一致），预览提示。

## 六、实现分工（遵守"常驻逻辑用 Rust"）

- `core/src/config_share.rs`（新）：导出生成（含注释与占位）、内部规则与自由文本检查、解析、合并计划、旧出口保护 JSON 识别；
  经 C ABI 暴露 `ac_share_export` / `ac_share_plan` 两个 JSON 进出的函数。加 `toml` crate 只用于解析，导出文本由自己按固定顺序写出；
  加依赖后重跑 `scripts/make-rust-notices.sh`。
- Swift：通用页两个按钮、导出与导入两张表单、文件面板、安全输入框、钥匙串写入、偏好写入与撤销。
- 开销：只在打开表单时运行，关上即释放；不加计时器、不常驻任何数据，常驻路径不变，按规矩在实现汇报里附 `footprint` 对照。
- 没有新的系统文件；导出文件放在用户选的位置，归用户所有。

## 七、首版范围

- 做：第二节"带上"与"勾选"的五部分；TOML 导出（预览与文件一致）；导入预览、合并/替换、冲突选择、占位补填、待补全、撤销；
  兼容现有出口保护 JSON 备份。
- 不做（以后再看）：按需连接、双击文件打开（注册文件类型）、只导出选中的几条、二维码/链接分享、文件签名。

## 八、我替用户定的默认（不同意再改）

1. 隐去用类型化占位，不用掩码（4.1 末尾的理由）。
2. Cisco 节默认不导出，勾选才带上。
3. 按需连接首版不导出。
4. 代理地址默认隐去，但允许分享者勾选保留（共用服务器的场景）；密码与用户名永远不能保留。
5. 同名代理默认"两个都留"，导入的改名。
